# Image Prompts

The working image-generation prompts for Language Bridge are kept **outside the
repo**, in `~/projects/puente-image-prompts.md`, alongside the author's other
generation prompts. That file holds the main-site hero, the Cognate Detective
module hero, optional per-item object images, and the future Academic Language Lab
and Newcomer Navigator heroes/scenario templates.

Rules that govern all art (spec §33–§34) are restated there:

- Instructional text must never depend on image-rendered text.
- Generated images only for hero scenes, scenarios, objects, classroom context.
- Project-created artwork only, CC BY 4.0, palette anchored on the brand tokens.
